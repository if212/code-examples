# Migration, as a Skill

A 37-second landscape explainer (1920×1080, 30fps, English, silent) made with [Remotion](https://www.remotion.dev/). It shows how an AI agent skill makes Spark → Snowflake migrations faster: you write the migration know-how once, then just ask.

| Time | Scene | Headline |
|---|---|---|
| 0–5s | S1 Pain | 12 Spark jobs. / Same fixes. Every job. |
| 5–9s | S2 Idea | Write the know-how *once*. |
| 9–14s | S3 What a skill is | That's an agent *skill*. (Playbook · Mappings · Checks) |
| 14–19s | S4 How you use it | Just ask. |
| 19–25s | S5 Result | Converted. And checked. / It converts. You review. |
| 25–29.5s | S6 Trust | It knows the traps. (NULL ordering) |
| 29.5–33s | S7 Team | Same playbook. Whole team. |
| 33–37s | S8 End card | Migration, as a *skill*. |

All counts on screen (12 jobs, 10 converted, 10/10 match, 2 need you) come from a demo project defined in `src/demoData.ts`. They are not benchmarks.

## Run

```bash
npm install
npm run studio      # preview in Remotion Studio
npm run render      # out/spark-to-snowflake-skill.mp4
npm run thumbnail   # out/thumbnail.png (mid-wave frame)
npm run typecheck
```

Every asset is local: fonts are loaded from `public/fonts` (copied from `@fontsource`), and the background orbs and grain are pre-rendered PNGs in `public/grain`, generated by `scripts/make-grain.py`. Each scene can also be previewed on its own with the `S1`–`S8` compositions.

## Structure

- `storyboard.json`: the original production spec (scene timings, copy, style, layout). Copy was tightened during review; the code is the source of truth.
- `src/theme.ts`, `src/layout.ts`, `src/timeline.ts`, `src/demoData.ts`: palette, fixed layout constants, scene frame ranges, demo data and copy.
- `src/components/`: the shared design system (background, headline reveal, glass tiles and job board, skill folder and card, light wipe, cursor, icons).
- `src/scenes/S1.tsx`–`S8.tsx`: one component per scene, with scene-private parts in `src/scenes/s<N>/`.
- `src/Main.tsx`: the full film (global background, scene sequences, light-wipe transitions).
